## 3. Mallet-42k, 2026-10-17 to 2026-10-26 (M10 tail, M12)
Source: git log and commit bodies (the repo's STATUS.md has the M10/M12 terrain and e2e rows; HANDOFF.md is stale).
- **Terrain layouts from a published pack:** WTC 2025 map pack scaled from 60x44 to 44x30 by `tools/terrain/wtc-to-cp.mjs` from `tools/terrain/wtc2025-source.json`; 12 pieces each, 180-degree symmetric; `tools/terrain/lanes.ts` + `tests/data/terrainLanes.test.ts` check that the largest base (130 mm) can reach every marker from every zone; ruin upper floors widened to 2.25" so a 40 mm base stands on them (`terrainFloors.test.ts`). A charge/fight end point at ground level under a floor then lands on the floor (known interpretation). Reusable idea: generate layouts from a source file with a script and test lanes/reachability, never hand-place.
- **E2E harness rot:** the projection helper hard-coded a camera that went stale when the camera rig changed, so every deployment click missed; the helper now reads the live camera (`window.__malletCamera.get()` exposes polar/fov). A missing favicon (404) failed every spec's "no console errors" check. Playwright honours `PW_CHROMIUM_PATH` for a preinstalled Chromium of another revision; software WebGL re-renders per mouse move so use fewer orbit steps.
- **Presentation fixes (M12):** a shot plays dice first, then the volley, with saves and deaths landing with their shots; the HUD (round, phase, scores, next-phase prompt) waits for the volley; the 6 s presentation stall guard fired during long dice windows, so the director re-arms it while a dice window or volley is actually playing (20 s cap with no progress); the bot's last deployment shares an engine step with the first-turn roll-off, so its camera visit flew after two banners until visits were played as soon as the step's deployments end and only the visited unit is revealed early.
- **Cinematic camera (2026-10-25):** behind the whole firing unit while the volley flies, close-up of each target on its first damaging shot, return to the player's view; covers overwatch; toggle in settings, on by default, skipped at instant speed and in hot-seat, player input cancels. During deployment the camera visits each unit the bot places and each reserve arrival.
- **Placement ghosts:** markers drew every model as the same ring so big and oval bases looked tiny until deployed; every deploy/reserve/move preview now draws the model's own base (ovals turned with facing) with a translucent ghost of the real figure, red where illegal; press-and-drag on the board while placing moves the whole formation (lifted above the finger on touch).
- **Save and Continue:** autosave after every accepted action (engine replay save plus bot tier, hot-seat and faction choices in one versioned envelope); start screen shows a Continue card (factions, round, phase, opponent, time); Continue opens on the current board without replaying animation; a save that no longer replays to the same position (rules update, bad data) is discarded with a notice; cleared when the game ends.
- **Audio on iPhone:** iOS Safari only lets `touchend`/`pointerup`/`click` resume an AudioContext; the manager unlocked on the first `touchstart` and removed its listeners, so sound never started. Fix: listeners stay for the session and retry until the context runs (also after a call or app switch suspends it), prime the context with a silent buffer inside the gesture, retry the ambient loop on the next gesture if autoplay refused it, and use the `playback` audio session so it plays through the silent switch.
- **Music stingers:** eight proposed stingers plus a picker page to audition them over the battlefield drone; accepted ones play every few minutes over the drone, ducking it while they sound.
- Camera feel ported from the Warmachine project: undamped OrbitControls, right-drag orbit, middle-drag or WASD pan, four eased presets (top, your edge, far edge, follow selected; tweens of at most 600 ms, interruptible), `T` top-down, `F` focus selected, `V` cycle. Event log moved to a right-edge drawer; deploy picker as a wide bottom strip. AI fix: melee-leaning squads stopped camping in their corner (Crusader squad stuck). GLB figures fit their datasheet bases (Impulsor scale, oval orientation, sideways hulls).
- Folder hygiene: `git status` in that checkout shows `elevenlabs.token.rtf` as untracked and not ignored (the `*.token*` gitignore gap named in the README) and a mangled folder named after a Windows temp path with the backslashes stripped. Do not copy either into a new project.

## 5. lorecannae (Disney Lorcana), 2026-10-24: a 6-hour overnight build

- **AI:** one opponent ply beat every weight sweep; common random numbers are mandatory when comparing candidates by rollout (without them Hard skipped early inks, 3.7% empty turns; after 0.6% and +13 points); measure on holdout seeds (a 56.7% change was 45% on fresh seeds). Normal beat the one-ply AI 80%, Hard beat Normal about 58%.
- **Owner feedback on day two** (PLAN D17 and commit bodies): card art redone so each card shows the actual character in MGSD proportions with an animation-style direction (FLUX.1 dev after the owner picked audition C; licence non-commercial noted; identity table of 87 characters written from the official cards as reference only, no img2img; 111 of 136 first pass, 25 re-rolled); the interface re-themed from Starbound sci-fi to an enchanted storybook ("This is not Star Wars"); the card preview's rules plate made translucent so art shows through.
- **GPU reservation lock:** a file `C:\Claude Code Projects\.gpu-lock` agreed with the Murder Squad session turned a blocked night into done-by-3am. ## 8. Cross-project gotchas new since 2026-10-17
- **Privacy hook gap:** `.git/hooks/pre-commit` with `privacy-patterns.txt` refuses commits adding the owner's name or home path, but in a git worktree `.git` is a file, so the hook cannot find the pattern file and passes silently. Point the hook at `git rev-parse --git-common-dir`, or grep the staged diff by hand before every worktree commit.
- **CRLF/LF churn** from parallel agents on Windows (whole-file diffs): `.gitattributes` with `* text=auto eol=lf`, `*.bat text eol=crlf`, then renormalise once; `git diff --ignore-cr-at-eol --stat` shows the real change.
- **Hunyuan 2.1 shape needs about 40 GB of Windows commit charge** (GPU allocations count): free memory first and keep the pagefile large; a failed shape stage is masked by a stale `outputs/<slug>/shape.glb` being re-painted, so clear them first and require `shape done` per slug in the log. Check free space on both drives of the second PC before a batch. Stop the local studio services when a session is done with them (owner rule, 2026-10-18). Launch long remote jobs detached with `schtasks`, not over an attached ssh (10-minute tool cap).
- **Audio Studio lives only on an unmerged worktree branch** of the `3D Model Generation` repo (`claude/ai-audio-generation-packages-2714d8`, worktree under `.claude/worktrees/`), as of 2026-10-26; a worktree cleanup would delete the only checked-out copy. Check `curl http://localhost:7890/api/status` first and do not modify that repo from a game project.
- **Parallel subagents leave orphaned wait-loop shells:** one wait per tool call, never chain polling loops across agents.
- **Per-item quality gate with a concrete reference** (side-by-side with an on-style figure, measured head ratio) instead of "check each image": 32 off-model concepts passed the vague gate (Murder Squad 2026-10-24).
- **Pipeline every stage:** a concept goes into the GLB queue the moment it renders, a GLB is finalised and wired the moment it lands, a team's verification starts when its implementer finishes (already rule 13 in the README; confirmed repeatedly by the batch timings).
- **Stripped-backslash folders:** two projects (Mallet-42k and Fell-in) ended with directories named after a Windows path with the backslashes removed, apparently from a path written through shell escaping. Write Windows paths with the Write tool or forward slashes, and check `git status` for stray top-level folders.
- **Public release caveat unchanged:** the owner prefers public Pages for playtests with the concern stated once; takedown docs must be rewritten in the commit that changes deployment.
