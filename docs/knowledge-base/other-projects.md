## MANAFORGE cross-project documents
**MALLET-42K-LESSONS.md** (the series' view of Mallet as the control group with a different stack and method): day one produced a full spec, a 402-item checklist, frozen contracts and workflow scripts, and nothing playable; day two ran out of tokens twice; the owner reset to "playable first", after which a 100-game sim and the first playable client landed the same day; about 4.8M tokens before the first playable. Verdict: don't repeat the big-spec experiment; aim adversarial verification at one genuinely hard subsystem. If multi-agent workflows are used: one stage at a time with commit and push after each; after a dead run `git status`, gates, commit by hand, rerun; each agent owns an explicit file list and never edits the status file, commits or installs; route findings to the owning loop; "foreground only" with run-time caps; cap research and name spec sections. Playtest complaints that generalise: every prompt names its subject; never draw a result behind the prompt that asks about it; hovering an option highlights the exact object; show the opponent's relevant numbers in your prompt; every number from the engine; pacing is a feature (about 2.4 s announcements, any click skips); measure audio (crest factor); read prompt context from state. Presentation: separate presented state from live state; bot waits for presentation idle; bound every wait with a watchdog; rate-limit frequent sounds; `instant` speed mode.

**OVERNIGHT-BUILD-PLAYBOOK.md** (from the RIVALFORGE overnight run, game-agnostic): (1) question round: ask only where a wrong guess costs rework, two batches of at most 4, state every other decision as a default; (2) order of work: `.gitignore` alone, rights findings, CLAUDE.md, the rulebook (authority doc), engine spine, content, AI, interface (the playable milestone), art, sound, registers; every stage ends runnable; state what gets cut first; (3) authority document before content; (4) a convention becomes a tool that fails the build (`test`, `check-pages`, `stamp-assets --check`, `check-art`, art-prompt lint); (5) measure: play both seats, count decisive results only, hold changes to a holdout, commit negative results, measure AI behaviour such as empty-turn rate; (6) spend in a sample first (`--dry-run`, then three, then the batch, idempotent); (7) verify in the real browser (a silent `|| {}` fallback once drew placeholder art for 59 paid renders); (8) commit at checkpoints with mechanism-describing messages; (9) four registers: DEVIATIONS, BALANCE, TODO, `defects.js`; PLAN.md alone owns decisions; (10) regrets: declare the asset manifest first, build self-diagnostics with the feature, don't let the fuzzer stand in for AI testing, ask one question about feel.

## Cross-project conventions observed
- **Docs:** `CLAUDE.md` (regime and hard rules), `PLAN.md` (owns every decision plus dated Status), `DEVIATIONS.md`, `TODO.md`, `data/defects.js`, `NOTICE.md` and `docs/takedown.md`, `HANDOFF*.md`; the 3D games use `CLAUDE.md`/`HANDOFF.md`/`STATUS.md`/`PLAN.md`/`docs/needs-rules-check.md`/`docs/KNOWLEDGE-BASE.md` instead.
- **Regime split:** reproduction (fidelity is the product) vs original design. Real names default with an original-name pack as the withdrawal lever.
- **Engine (card games):** no build; `legalActions`/`apply`/`isTerminal`/`whoActs`; one resolution queue; seeded RNG inside `apply`; cards as data; unreadable abilities refused; no silent fallbacks; "never assume a choice", "open information is a rule"; one door per rule with greps for bypasses.
- **Process:** verify in the real browser; commit messages describe the mechanism; per-card behaviour tests, headless sim, bug-report black box with replayer, arena counting decisive results; playable first; `ls` every path a document claims.
- **Agents and tokens:** single agent by default; helpers on Sonnet with explicit file lists, never committing; one agent per worktree outside OneDrive; contact sheets instead of full-size renders; the owner is cost-sensitive and twice hit the usage limit.
- **IP:** mechanics functional, names/art/text expressive; NOTICE and takedown steps; non-commercial; no official art or audio. Public: MANAFORGE, FABFORGE, GRAND LINE, Starbound Legions, Marble Forge, Skyjo, Aria's Game, Mallet 42k, Whirr Machine, WarMechForge, Dead of Winner, Fell-in, Not Enough Minerals.
