# Mancermundo

An unofficial, non-commercial fan project: a 3D browser skirmish game based on the rules of Necromunda, with original MGSD-style figures. Goliath vs Escher on a Zone Mortalis board, player vs AI or hotseat.

Play: https://dragoonant.github.io/mancermundo/

Not affiliated with or endorsed by Games Workshop. Necromunda, Goliath, Escher and related names are trademarks of Games Workshop Ltd. No Games Workshop text, art or logos are included; all rules descriptions are written in our own words, and you need the official books to know the rules in full.

Made by **evilgouki** with Claude Code.

## Develop
```bash
npm install
npm run dev
```
Gates: `npm run typecheck`, `npm test`, `npm run validate:data`, `npm run sim`, `npm run e2e`.
